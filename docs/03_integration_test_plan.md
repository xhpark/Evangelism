## 1. 종단 간 (End-to-End) 통합 테스트 시나리오

```
[앱 실행] ➔ [Welcome 저작권·면책 동의 게이트] ➔ [메인 5대 탭 네비게이션 진입]
  ├── Tab 1: [학습/청취] (0.8x~2.5x 배속, 4대 반복모드, 5손가락 연동, 블라인드 가림막)
  ├── Tab 2: [순발력/전환] (1s/2s/3s 타이머 STT, 듀얼 점수표, 6대 전환문장 덱)
  ├── Tab 3: [성경덱] (핵심 8구절 암송, 빈칸 퀴즈 모드, TTS 구절 듣기)
  ├── Tab 4: [실전시험] (시작 문두 3/4/5단어 ➔ 7대 연계 완주 시험, Myers Diff 성적표)
  └── Tab 5: [설정] (한국어 TTS 보이스/톤 프리셋, 개별 대본 수정, TXT 일괄 임포트, 저작권 조회)
```

## 3. 실기기 빌드 및 배포 명령어

```bash
# 디버그 APK 빌드
flutter build apk --debug

# 실기기(Galaxy S24 Ultra) 설치 및 실행
adb -s R3CX60PDSTA install -r build/app/outputs/flutter-apk/app-debug.apk
adb -s R3CX60PDSTA shell am start -n com.evangelism.just_ee.just_ee_master/.MainActivity
```
