## 1. 앱 시작하기 및 기기 인증

### 1.1 저작권 및 개인정보 동의 게이트
* 앱을 실행하면 저작권·면책과 개인정보 처리 범위가 함께 표시됩니다.
* **저작권/면책 동의**와 **개인정보 수집·이용 동의**를 각각 체크해야 시작 버튼이 활성화됩니다.
* 활성화를 위해 기기 코드·성명·소속·OS·앱 버전이 서버로 전송됩니다. 간증·수정 대본·음성인식 결과·시험 기록은 기기에만 저장됩니다.

### 1.2 🔐 일회용 코드로 기기 활성화
* 최초 1회 실행 시 **[기기 인증 및 라이선스 활성화]** 화면이 나타납니다.
* 이 화면에서는 **세 가지를 모두** 입력해야 활성화됩니다.
  1. **훈련생 성명** (예: 홍길동)
  2. **소속 교회** (예: 서울OO교회)
  3. **일회용 활성화 코드** — 관리자가 해당 훈련생에게 배정한 16자리 코드
* 관리자는 기기 코드를 받기 전에도 코드를 미리 생성할 수 있습니다. 화면의 **기기 코드(`EE-XXXX-XXXX-XXXX-XXXX`)**는 발급 필수값이 아니라 대상 확인과 장애 대응에 사용합니다. 코드는 정상 활성화에 한 번 사용된 뒤 그 기기에 귀속되어 재사용할 수 없습니다.
* 활성화 후에는 서버가 발급한 기기 토큰으로 승인 상태를 확인합니다. 보안 방식 변경·토큰 취소·기기 데이터 초기화 때는 새 코드로 재활성화해야 합니다.

### 1.3 관리자가 다른 훈련생에게 설치 링크와 코드를 전달하는 순서

1. 개발자는 실제 서버 주소가 빌드 설정에 들어간 정식 서명 release APK를 준비합니다. 디버그 APK나 Apps Script 주소를 전달하지 않습니다.
2. APK를 Google Drive 등 접근을 통제할 수 있는 저장소에 올립니다. 제한 테스트라면 대상 이메일만 열고, 넓게 배포해야 할 때만 **링크가 있는 사용자/보기 전용**으로 설정합니다.
3. 훈련생에게는 **APK 다운로드 링크만** 전달합니다. Apps Script `/exec` 주소와 라이선스 관리 시트 링크는 관리자만 보관합니다.
4. 관리자는 `activation_codes` 탭에서 `UNUSED` 코드 하나를 선택해 그 훈련생에게 개인 메시지로 전달합니다. 여러 명에게 같은 코드를 보내지 않습니다.
5. 훈련생은 APK를 설치하고 앱을 연 뒤 두 동의를 직접 체크합니다. Android가 차단하면 APK를 연 브라우저 또는 Drive 앱에만 **알 수 없는 앱 설치 허용**을 잠시 허용합니다.
6. 활성화 화면에서 성명·소속·코드를 입력합니다. 성공하면 해당 코드는 `USED`가 되고 사용 기기와 사용 시각이 기록됩니다.
7. 관리자는 `licenses` 탭에서 해당 행의 상태가 `APPROVED`인지 확인합니다. 문제가 생기면 코드 원문을 공개 채팅에 올리지 말고 상태·기기 코드·오류 문구만 대조합니다.

`createActivationCodes(count)` 자체는 1~100개 일괄 생성을 지원합니다. 다만 Apps Script 편집기의 **실행** 버튼은 인수를 전달하지 않으므로 그대로 실행하면 1개만 생깁니다. 예를 들어 10개가 필요하면 편집기에 아래 관리자용 래퍼를 추가하고 저장한 뒤, 함수 목록에서 `create10ActivationCodes`를 선택해 실행합니다.

```javascript
function create10ActivationCodes() {
  return createActivationCodes(10);
}
```

이 보조 함수로 코드를 생성하는 것만으로는 웹앱 재배포가 필요하지 않습니다. 활성화 처리 로직 자체를 변경했을 때만 새 버전으로 웹앱 배포를 갱신합니다.

## 2. 1. 학습/청취 탭 (듣고 따라하기)
자연스러운 음성으로 복음 전문을 들으며 눈과 귀로 익히는 기본 학습 공간입니다.

### 💡 주요 기능 및 조작법
1. **상단 챕터 선택 바**:
   * `1. 서론`, `2.1 은혜`, `2.2 인간`, `2.3 하나님`, `2.4 그리스도`, `2.5 믿음`, `3. 결신`, `4. 즉석 양육` 중 원하는 챕터를 터치하여 이동합니다.
2. **🖐️ 5손가락 복음 개요 (Hand Outline)**:
   * 2대 복음 대지에서는 상단에 손가락 가이드가 나타납니다.
   * `👍 엄지(은혜)`, `☝️ 검지(인간)`, `🖕 중지(하나님)`, `💍 약지(그리스도)`, `🤙 소지(믿음)`를 누르면 해당 대지로 즉시 이동합니다.
3. **문장 카드 조작**:
   * 문장 카드를 터치하면 해당 문장을 즉시 발화합니다.
   * 오른쪽 상단의 **[스피커 아이콘]**을 누르면 그 문장만 개별 청취합니다.
   * **[연필 아이콘]**을 누르면 해당 문장을 나만의 표현으로 즉시 수정할 수 있습니다.
   * **긴 예화/기도문 자동 스크롤**: 내용이 긴 문장은 음성이 흘러나오는 도중 화면이 아래로 부드럽게 스크롤되어 글자가 항상 시야에 들어옵니다.
4. **하단 오디오 컨트롤 바**:
   * **배속 조절**: `0.8x`, `1.0x`, `1.2x`, `1.5x`, `2.0x` 중 선택. 표시된 배속과 실제 재생 속도가 정확히 일치합니다.
   * **재생 모드 (4가지)**:
     - `현재 챕터 무한 반복 (추천)`: 선택한 챕터 전체 문장을 계속 반복해서 듣기.
     - `현재 챕터 1회 재생`: 선택한 챕터를 한 번만 완주.
     - `선택문장 무한 반복`: 잘 안 외워지는 특정 선택 문장만 집중 반복.
     - `전체 전문(1~8) 완주 재생`: 서론부터 마침기도까지 40개 문장 전체를 연속 재생.
   * **👁️ 가림막(블라인드) 버튼**: 텍스트를 가려놓고 음성만 들으며 머릿속으로 떠올리는 훈련 모드입니다.

## 3. 2. 순발력/전환 탭 (1초 반사 훈련)
문장의 시작 단어와 마지막 단어를 보고 뒷문장을 순발력 있게 암송하는 트레이닝입니다.

### 💡 훈련 방법
1. **난이도 선택**:
   * `초급 (앞뒤 5단어 / 1.0x 속도)` ➔ `중급 (앞뒤 4단어 / 1.2x 속도)` ➔ `고급 마스터 (앞뒤 3단어 / 1.5x 속도)`
   * 어디까지 암송해야 하는지 명확히 알 수 있도록 첫 부분과 마지막 부분의 단어를 함께 제시(`시작 단어 ... 끝 단어`)합니다.
   * 문장 길이에 맞춰 1.0x(초급), 1.2x(중급), 1.5x(고급) 낭독 소요 시간에 비례한 타임아웃 시간이 동적으로 설정됩니다.
2. **훈련 시작**:
   * **[n초 순발력 테스트 & 음성 인식 시작]** 버튼을 누르면 문장 길이에 맞게 계산된 제한 시간 동안 타이머가 카운트다운됩니다.
   * 화면에 제시된 시작 단어와 끝 단어를 참고하여 전체 문장을 마이크에 대고 즉시 말씀하세요.
3. **마이크가 안 될 때**:
   * 권한이 없거나 음성 인식을 쓸 수 없으면 화면에 **붉은 안내 문구**가 나타납니다. 안내에 따라 마이크 권한을 허용해 주세요.
4. **듀얼 성적표 확인**:
   * 답변이 끝나면 **⚡ 순발력 점수(음성이 감지되기까지 걸린 초)**와 **🎯 정확성 점수(원문 어절 대조 일치율 %)**가 동시에 채점되어 나타납니다.
5. **🔗 6대 전환문장 덱**:
   * 상단 두 번째 탭에서는 대지와 대지를 연결하는 핵심 전환문장 6개만 모아서 집중 마스터할 수 있습니다.
   * 이 목록은 교재 대본에서 직접 뽑아오므로, 설정에서 대본을 고치면 목록도 함께 바뀝니다.

## 4. 3. 성경덱 탭 (핵심 8구절 암송)
복음 제시 전문에 실제로 인용되는 8개 핵심 성경 구절을 장/절 번호와 함께 완벽히 외우는 공간입니다.

| 순서 | 대지 | 구절 |
| :---: | :--- | :--- |
| 1 | 서론 (성경 기록 목적) | 요한일서 5:13 |
| 2 | 2.1 은혜 | 에베소서 2:8-9 |
| 3 | 2.2 인간 | 로마서 3:23 |
| 4 | 2.3 하나님 (사랑) | 요한일서 4:8b |
| 5 | 2.3 하나님 (공의) | 출애굽기 34:7b |
| 6 | 2.4 예수 그리스도 | 이사야 53:6 |
| 7 | 2.5 믿음 | 사도행전 16:31 |
| 8 | 3. 결신 (구원의 확신) | 요한복음 6:47 |

### 💡 훈련 방법
1. **성경 구절 넘기기**:
   * 상단 구절 칩(`에베소서 2장`, `로마서 3장`, `요한일서 4장` 등)을 누르거나 하단의 `[이전 구절]` / `[다음 구절]` 버튼으로 넘깁니다.
2. **전체 구절 연속 반복 듣기**:
   * 성경 카드 우측 상단의 **스피커 아이콘** 또는 카드 하단의 **[전체 8구절 연속 반복 듣기]** 버튼을 누르면 1번 구절부터 8번 구절까지 순서대로 읽고, 1번으로 돌아가 무한 반복 재생합니다.
   * 재생 중에는 현재 낭독 중인 구절로 카드가 자동 전환되며, 버튼이나 스피커를 다시 누르면 즉시 정지됩니다.
3. **빈칸 퀴즈 모드**:
   * 오른쪽 상단 **[?] 퀴즈 아이콘**을 누르면 핵심 단어가 `[ ___ ]` 빈칸으로 마스킹되어 자가 테스트를 할 수 있습니다.

## 5. 4. 실전시험 탭 (모의 구두시험)
실제 전도폭발 구두시험 및 현장 전도 환경과 100% 동일한 방식으로 치러지는 음성 실전 시험장입니다.

### 💡 6대 실전 시험 모드
1. **전환 ➔ 다음 단락 연계 (강력 추천)**:
   * 전환 문장 시작 문두가 제시되면 전환 문장을 완성하고, 이어서 다음 대지 전체(원리, 예화, 다음 전환문장)를 막힘없이 연속 암송합니다. (실전 특성에 맞춰 순수 성경 구절은 제외)
2. **예화 집중 완주**: 햇빛·공기·물, 9만 번 죄, 가르시아 장군, 죄의 책 등 긴 스토리 전체를 완주합니다.
3. **서론/결신 핵심 문답**: 제1/2 진단질문, 결신 3대 의미, 영접기도 및 확신기도를 암송합니다.
4. **즉석 양육 항목별**: 성경, 기도, 예배, 교제, 전도, 마침기도를 항목별로 암송합니다.
5. **실전 무작위 출제**: 전환·예화·서론/결신·즉석양육 4개 영역 중 하나를 무작위로 골라 매번 새로운 1문제를 출제하는 모의고사입니다.
6. **전체 전문 100% 완주**: 1번 서론부터 8번 마침기도까지 순수 성경 구절 암송을 제외한 34개 문장 전체를 쉬지 않고 완주합니다.

> ℹ️ **성경 구절 암송 안내**: 실제 1:1 전도 현장에서는 복음 제시자가 성경 구절을 외워서 읊기보다는 성경 책자를 펼쳐 직접 읽어 주므로, 실전 음성 시험에서는 순수 성경 구절이 제외됩니다. 성경 구절 암송은 **[3. 성경덱]** 탭에서 집중 훈련하실 수 있습니다.

### 💡 긴 시험을 볼 때 (중요)
* 암송 도중 숨을 고르거나 잠시 멈춰도 **수음이 자동으로 이어집니다.** 앞서 말한 내용이 사라지지 않으니 안심하고 끝까지 암송하신 뒤 마이크 버튼을 눌러 마치세요.
* 전체 완주처럼 긴 시험은 채점에 몇 초가 걸릴 수 있으며, 이때 **"채점 중입니다..."** 표시가 나타납니다. 화면이 멈춘 것이 아니니 잠시 기다려 주세요.
* 인식된 음성이 하나도 없으면 0점 처리 대신 안내 문구가 나타납니다.

### 💡 문두 힌트 레벨 조절
* `초급(5단어)` ➔ `중급(4단어)` ➔ `고급(3단어)` 칩을 눌러 시작 힌트 단어 수를 조절할 수 있습니다.

### 💡 정밀 채점 성적표 (LCS 기반 어절 대조 리포트)
* 발화가 끝나면 **총점(100점 만점)**과 **평가 등급(탁월/합격/재도전)**이 산출됩니다.
* **원문 대조 색상 분석 (최장 공통 부분 수열 LCS DP 역추적 적용)**:
  - 🟢 **초록색**: 정확히 일치한 단어 (문장을 건너뛰어도 뒤따르는 정답 단어를 정확히 추적)

  - 🟡 **노란색/주황색**: 추가되거나 다르게 발음된 변형 단어

## 7. 자주 묻는 질문 (FAQ)

**Q. 일회용 활성화 코드는 어디서 발급받나요?**
A. 개발자 박상환(`xhpark@naver.com`)에게 요청하세요. 관리자는 코드를 미리 생성해 훈련생별로 하나씩 배정할 수 있습니다. 기기 코드는 발급 자체에는 필수가 아니지만 대상 확인과 장애 대응을 위해 함께 보내는 것이 좋습니다. 정상 활성화에 사용된 코드는 다시 사용할 수 없습니다.

**Q. 인터넷이 안 되는 곳에서도 앱을 사용할 수 있나요?**  
A. 최초 활성화에는 인터넷 연결이 필요합니다. 활성화 뒤 일시적으로 오프라인이 되어도 로컬 승인과 학습 데이터는 유지되지만, 원격 승인·차단 상태는 다시 연결될 때까지 갱신되지 않습니다. 음성 인식은 단말의 오프라인 한국어 음성 모델 설치 여부에 따라 제한될 수 있습니다.

**Q. 성경덱 구절이 9개에서 8개로 줄었습니다. 빠진 건가요?**  
A. 아닙니다. 복음 제시 전문에 실제로 인용되지 않는 3구절(로마서 6:23, 마태복음 5:48, 요한복음 1:1)을 정리하여, 교재 본문과 정확히 일치하는 8구절만 남긴 것입니다.

**Q. 예전에 있던 "교재 기본 대본으로 전체 복원" 버튼이 안 보입니다.**  
A. 훈련생이 정성껏 수정한 문장이 한 번의 실수로 전부 지워지는 사고를 막기 위해 해당 버튼을 제거했습니다. 문장 복원은 각 문장의 `[✏️ 수정]` 기능으로 개별 진행해 주십시오.
