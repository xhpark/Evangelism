## 1. 시스템 아키텍처 (System Architecture)

본 앱은 유지보수성, 테스트 용이성, 모듈 간 결합도 최소화를 위해 **Clean Architecture + MVVM 패턴 (Provider)**을 채택합니다.

```

│     1. StudyScreen (TTS 0.8x~2.5x 배속, 4대 재생모드, 5손가락 연동)     │
│     2. QuickTriggerScreen (1s/2s/3s 순발력 STT & 6대 전환문장 덱)      │
│     3. ScriptureDeckScreen (핵심 9구절 암송 덱 & 빈칸 퀴즈)            │
│     4. VoiceExamScreen (시작 문두 3/4/5단어 제시 ➔ 7대 연계 완주 시험)  │
```

## 3. 실전 시험 엔진 (`RandomExamEngine`) 설계

전환문장 완성 후 다음 대지 전체로 자연스럽게 이어지는 현장 전도 환경을 구현하기 위해 **7대 연계 시험 모드**를 지원합니다.

### 3.1 7대 실전 시험 출제 모드
1. **전환 ➔ 다음 단락 연계 시험**: 전환 문장 앞부분을 제시하면 전환 문장을 완성하고, 이어서 다음 대지 전체(원리, 성경, 예화, 전환문장)를 연속 암송.
2. **예화 집중 완주 시험**: 예화의 도입 문두를 제시하면 해당 예화 스토리 전체를 완주 암송.
3. **성경 구절 암송 시험**: 성경 구절 앞부분을 제시하면 장/절 및 본문 전체를 암송.
4. **서론/결신 핵심 문답 시험**: 제1/2 진단질문, 결신 3대 의미, 영접기도 및 확신기도 완주.
5. **즉석 양육 항목별 시험**: 성경, 기도, 예배, 교제, 전도, 마침 기도 항목별 단락 완주.
6. **실전 무작위 출제**: 28개 실전문항 중 무작위 1문항 출제.
7. **전체 전문 100% 완주**: 1번 서론부터 8번 즉석양육 마침기도까지 38개 문장 전체 완주.

### 3.2 레벨별 가변 문두 힌트 (Dynamic Lead-in Triggers)
* **초급 (Beginner)**: 문두 **5단어** 제공
* **중급 (Intermediate)**: 문두 **4단어** 제공
* **고급 (Master)**: 문두 **3단어** 제공

## 4. 정밀 보완된 핵심 엔진 상세 설계

### 4.1 🛠️ 한국어 구어체 정규화기 (`KoreanTextNormalizer`)
실제 음성 발화 시 발생하는 구어체 오차를 완벽히 보정하는 3단계 정규화 파이프라인:
1. **불필요한 추임새/간투사 필터링:**  
   * 발화 중간의 `"어...", "음...", "그...", "저...", "아..."` 등을 자동 감지하여 채점 대상에서 제외 (감점 방지)
2. **성경 장/절 및 한글 숫자 상호 변환:**  
   * STT 출력 예: `"에베소서 이장 팔절에서 구절"` / `"에베소서 2장 8-9절"` ➔ 표준 토큰 `"에베소서 2장 8절 9절"`로 통일
   * 한글 수사(일, 이, 삼... 십, 백) ➔ 아라비아 숫자(1, 2, 3... 10, 100) 자동 치환
3. **특수문자 및 띄어쓰기 유연성:**  
   * 문장부호(`,`, `.`, `?`, `!`, `-`) 정제 및 다중 공백 단일화

### 4.2 🎙️ STT 장기 연속 세그먼트 수음 엔진 (`STTService`)
* **세그먼트 연결 방식 (Continuous Session Stitching):**
  * 사용자가 발화 중 침묵하더라도 `isListening == true` 상태를 유지하며 내부 버퍼에 텍스트를 누적(`Buffer.append`).
  * 사용자가 직접 `[답변 완료]` 버튼을 누를 때까지 끊김 없이 연속 수음 지원.

### 4.3 📱 화면 꺼짐 방지 및 오디오 포커스 관리 (`DeviceHelperService`)
* `wakelock_plus` 연동:
  * TTS 2.5x 연속 청취 모드 및 STT 실전 시험 모드 구동 중 스마트폰 화면 절전 꺼짐 방지.
* 전화 수신 등 시스템 인터럽트 발생 시 오디오 자동 일시정지 및 복귀.

## 5. UI 반응형 및 법적 고지 설계

1. **TTS 자동 스크롤 추적**:
   * 활성 문장 변경 시 `EnsureVisible` 자동 정렬.
   * 180자 이상의 긴 문장(예화/기도문)은 발화 50% 시점에 하단부로 자연스럽게 추가 스크롤.
2. **픽셀 오버플로우 제로화**:
   * 모든 카드 타이틀 및 안내 텍스트에 `Expanded` 적용.
   * 버튼 배열에 `Wrap(spacing: 8, runSpacing: 8)`을 적용하여 화면 크기 및 글꼴 배율 변경 시에도 완벽한 레이아웃 유지.
3. **법적 고지 & 첫 화면 게이트 (`WelcomeTermsScreen`)**:
   * 앱 실행 시 저작권/개발자 정보/면책 조항을 표시하고 동의 체크 후에만 메인 화면으로 진입.
   * [설정] 탭에서도 상시 조회 가능.
